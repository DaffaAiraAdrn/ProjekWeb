Implementasi CNN untuk Klasifikasi Gambar

Published on: 12 May 2026

Pada laporan ini, kita menggunakan PyTorch untuk membangun model Convolutional Neural Network (CNN). Model ini dilatih menggunakan dataset yang terdiri dari berbagai kelas gambar. Hasil evaluasi menunjukkan akurasi sebesar 95% pada data uji.

Langkah-langkah yang dilakukan antara lain pra-pemrosesan data, definisi arsitektur model, pelatihan, dan pengujian. Seluruh proses dilakukan di Google Colab. Kode sumber dapat dilihat pada repository GitHub saya.

CNN terbukti sangat tangguh dalam menangani data visual dan mengekstraksi fitur secara hierarkis, menjadikannya pilihan utama untuk tugas computer vision modern.
